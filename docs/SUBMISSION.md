# Submission checklist

Deadline **Sat 31 Oct 2026, 11:59 pm IST**. Form: https://www.exasol.com/events/exathon-india-2026/submit-your-project/

Re-read the event page before submitting; dates have moved before.

## Rules

- [ ] Team of 1 to 3
- [ ] Exasol Personal is the data platform
- [ ] Public GitHub repo, MIT licence file at root
- [ ] Public or synthetic data only, stated in README
- [ ] Original work created during the challenge window

## Deliverables

- [ ] Problem statement (who has it, why it matters), from `docs/PROBLEM.md`
- [ ] Public code repository
- [ ] Pitch deck (PDF or PPT)
- [ ] Demo video, 3 minutes maximum
- [ ] README: overview, setup, usage
- [ ] Deployment instructions and run guide
- [ ] Licence file

## Judging, and where we show it

| Criterion | Weight | Evidence |
|---|---|---|
| Innovation & problem impact | 25% | RBI text on slide 1, problem sentence, fingerprint + date resolution in the first minute |
| Effective use of Exasol Personal | 25% | `WHY_EXASOL.md`, measured scale run, lineage from ledger to SQL step |
| Technical excellence | 20% | Exact decimals, oracle agreement, RBI fixtures, false-positive suite, CI |
| Solution design & UX | 15% | Screens built around the auditor's questions; gaps shown honestly |
| Documentation & reproducibility | 10% | One-command setup, run guide, LIMITS, cold start verified |
| Open-source quality | 5% | MIT, tests, CONTRIBUTING, generator documented, no secrets, small commits |

## Final pass

- [ ] Fresh clone on a second machine: setup, load, run, test all work from README alone
- [ ] No secrets, no `.env`, no large data files in git
- [ ] Every number in README, deck and video is in `STATUS.md` "Measured results"
- [ ] No "first"/"only" claims, no prevalence numbers
- [ ] Repo visibility is public
